### What we do
- 🔍 **Analyze** — map your real workflows, exceptions and reporting needs before touching architecture.
- 🚀 **Implement** — end-to-end deployment, configuration, data migration and go-live support.
- 🧩 **Develop** — custom modules and integrations for everything standard Odoo can't do.
- 🤝 **Support** — long-term partnership: server maintenance, upgrades and user training.

- ⬆️ **Migrate to Odoo 19** — database and custom-code migration, including frontend rewrites.
